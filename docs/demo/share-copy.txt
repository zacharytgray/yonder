My work is spread across computers: a laptop, a Mac mini that's always on, a PC with a GPU, and a Raspberry Pi. Each AI agent only knows the machine it runs on.

So I built Yonder. It connects my computers so the agent on any one of them can use all of them.

I text my agent "The Pi's disk is full, can you clean it up?" and it looks, then frees the space. "Run the training script on the PC" starts the job there, and I check on it later. "Use my Hugging Face token" works by name: the key comes from 1Password or Bitwarden, and the value stays out of output and logs.

It's one small program, with no server. It uses Tailscale and SSH, and it works with Claude Code, Codex, Pi and Hermes. To set it up, tell your agent: "Set up Yonder for me: https://github.com/zacharytgray/yonder". Open source, MIT, macOS and Linux.
